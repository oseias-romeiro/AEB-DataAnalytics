Project Overview

This project explores and analyzes public data published by the Brazilian Space Agency (AEB). The goal is to transform open government data into clear, accessible, and interactive insights.

The dashboard below presents information about Brazilian space objects, such as satellites, launch bases, vehicles, and entities involved in the national space program.

Interactive Dashboard

About the Data

The data used in this project comes from official open datasets provided by the Brazilian Government. All information is public and intended for transparency, research, and analysis purposes. This page is part of a personal data analytics portfolio and aims to demonstrate how public data can be transformed into meaningful insights through modern analytics tools.

Full source code, data pipeline, and documentation are available on GitHub
